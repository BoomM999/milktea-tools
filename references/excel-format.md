# Excel 导入配方格式规范（实测自 `C:\Users\1\Desktop\导入配方.xlsx`）

## 工作表结构

- 工作簿只有 2 个 sheet：`Sheet1`（数据）、`Sheet2`（空）。
- 数据仅在 `Sheet1` 的 **A-I 列**（9 列）。`max_row` 可能为 3342 等伪值，但实际有效数据约 182 行（依赖饮品数）。
- 无冻结、无合并、无下拉校验、无字体/填充/边框样式。

## 表头（第 1 行，A-I）

| 列 | 中文表头 | 英文字段名 | 取值示例 |
|---|---|---|---|
| A | 配方版本号 | version | `全国北京路通用` |
| B | 饮品名称 | drinkName | `凤梨冰奶`, `草莓冰奶`, `杨枝甘露（轻盈版）` |
| C | 杯型 | cup size | `大杯` |

| G | 原料名称 | materialName | `蔗糖`, `凤梨果浆`, `速冻草莓果酱`, `鲜牛乳`, `冷冻芒果浆`, `厚椰乳` |
| H | 原料用量 | materialDosage | `30`, `25`, `40` 等字符串数字 |
| I | 原料排序 | materialOutSort | *(当前样本为空)* |

## 数据行规则（实测）

- 一行 = 一款饮品在一个 (温度, 糖度) 组合下的**一种**原料用量。
- 组合顺序：按饮品 → 温度 → 糖度 → 原料 行展开。
- 同一 (饮品, 温度, 糖度) 下的原料固定数量：标准糖/七分/五分/三分糖 = 3 行（蔗糖 + 主料 + 基底），不额外加糖 = 2 行（无 蔗糖）。
- 行内取值约定：
  - A 列在该文件中**全是相同字符串** `全国北京路通用`（按"全国通用"理解）。
  - D、I 列即使在模板中存在，当前样本里**全部为空**。
  - H 列是 **字符串数字**（不是 int/float）。写入 Excel 时用 `str(int(value))`。
  - 重复行风格：A~F 复制当前组合上下文，G/H 列出对应原料。

## 组合矩阵（参考）

```
温度顺序: 正常冰 → 少冰 → 去冰 → 常温 → 热
糖度顺序: 标准糖度 → 七分糖 → 五分糖 → 三分糖 → 不额外加糖
原料顺序: 蔗糖(可选) → 主料(果浆/果酱) → 基底乳(牛乳/厚椰乳)
```

注：常温/热 常出现于"全温度"饮品；冷饮只允许 正常冰/少冰/去冰。

## 写文件示例（openpyxl）

```python
from openpyxl import Workbook
wb = Workbook()
ws = wb.active
ws.title = "Sheet1"
headers = ["配方版本号（version）", "饮品名称（drinkName）", "杯型（cup size）",
           "做法（addtional）", "温度（ice level）", "糖度（sugar level）",
           "原料名称（materialName）", "原料用量（materialDosage）",
           "原料排序（materialOutSort）"]
ws.append(headers)
for row in data_rows:
    ws.append(row)
wb.save(output_path)
```

不要触碰 `Sheet1` 之外的样式、Sheet2、不要创建多余工作表。
