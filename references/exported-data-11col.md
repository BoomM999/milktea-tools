# 配方数据.xlsx —— 11 列导出格式（学习参考，非生成目标格式）

> 目标生成格式仍是 9 列 `导入配方.xlsx` 模板；本文件描述导出文件的扩展结构，用于理解数据与原料命名。

## 文件概况

- 路径示例：`C:\Users\1\Downloads\配方数据.xlsx`
- 单工作表 `饮品配方数据`，11 列，约 11623 行（多版本/多渠道累积导出）。
- 无样式、无下拉、无冻结；I 列用量为字符串（两位小数，如 `100.00`）。

## 11 列结构

| 列 | 字段 | 说明 |
|---|---|---|
| A | 配方版本号（version） | 见下方版本号清单 |
| B | 饮品名称（drinkName） | 含杯型后缀：`黑糖珍珠奶茶(大杯)`、`杨枝甘露椰椰（大杯）`；香港/韩国/USA 带后缀 |
| C | 杯型（cup size） | `大杯` `中杯` `桶` `异形杯` `标准杯`；香港版 `大杯（香港）` 等 |
| D | SkuID | 导出样本中全空 |
| E | 做法（addtional） | 导出样本中全空 |
| F | 温度（ice level） | `正常冰` `少冰` `去冰` `常温` `热`；香港版 `正常冰（香港）` 等；`冰沙（香港）` `标准冰` |
| G | 糖度（sugar level） | `标准糖度` `七分糖` `五分糖` `三分糖` `不额外加糖`；香港版 `標準糖度（香港）` 等；`200%糖` `150%糖` `标准糖` |
| H | 原料名称（materialName） | 见 `material-dictionary.md` |
| I | 原料用量（materialDosage） | 字符串数字，两位小数，如 `30.00` |
| J | 原料排序（materialOutSort） | 导出样本中全空 |
| K | 二维码数据（qrCode） | 每行都有值，如 `500642-01-23-11` |

## 组合展开逻辑（与 9 列模板一致）

- 每行 = 饮品 × 杯型 × 温度 × 糖度 × 原料。
- 糖度顺序：标准糖度 → 七分糖 → 五分糖 → 三分糖 → 不额外加糖。
- 温度顺序：正常冰 → 少冰 → 去冰 → 常温 → 热（饮品允许的温度范围内）。
- 不额外加糖 → 无 `蔗糖` 行。
- 一款饮品行数 = Σ(各糖度的原料数 × 该糖度允许的温度数)。

## 二维码 K 列规律（仅供理解）

- 格式：`<产品编码>-<变体>-<糖度码>-<温度码>`，如 `500642-01-23-11`。
- 温度码：`23`=正常冰、`24`=少冰、`25`=去冰、`26`=常温、`27`=热（推断，未穷举）。
- 糖度码：`11`=标准糖度、`12`=五分糖、`13`=七分糖、`17`=三分糖、`18`=不额外加糖。
- 生成 9 列导入配方时**不需要** K 列。

## 判定"当前在用配方"的方法

1. 以最新 PDF（如"XX最新配料表"，含更新日期）为准，列出其中的饮品。
2. 在 Excel 中按 `饮品名` 匹配，优先看 `全国标准` 与 `标准` 两个版本（对应全国/商场渠道）。
3. 荔枝系列等区域产品挂 `全国北京路通用`；线上渠道看 `线上产品`。
4. 香港/韩国/USA 带后缀名称属于海外版本，一般不用。
5. 同饮品多版本并存时，行数多/含"升级版"且与最新 PDF 数值一致者为当前在用。
