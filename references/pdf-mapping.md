# PDF 配料表 → Excel 字段映射

来源 PDF：`前场配料`（内部文件，禁止外传），单页表格。

## PDF 表格列结构

每个品牌分组一个子表，列从左到右：

1. **饮品名称** — 单列（可竖跨 2 个杯型说明行）
2. **杯型** — 单列，写法：`大杯 / 热：22A纸杯 / 冰：700塑杯` 或 `大杯 / 700塑杯`
3. **制作（正常糖）** — 完整配方字符串：`蔗糖糖浆30克+黄金冻1.5漏勺（120克）+凤梨果酱1平塑勺（25克）+鲜牛乳40ml`
4. **七分糖/半糖** — 仅写 蔗糖糖浆 用量：`蔗糖糖浆20克`
5. **三分糖** — 仅写 蔗糖糖浆 用量：`蔗糖糖浆10克`
6. **温度** — `全温度` / `冰/少冰/去冰` / `冰/少冰` / 等

## 列 → Excel 字段映射

| PDF 元素 | Excel 字段 | 取值规则 |
|---|---|---|
| PDF 头部的"更新时间"或文件标题 | A 配方版本号 | 默认 `全国北京路通用`；PDF 文件名含其他标识时按其推断 |
| 饮品名称单元格 | B 饮品名称 | 原样保留（含括号、全角符号） |
| 杯型列（合并 22A/700 描述） | C 杯型 | 恒写 `大杯`（忽略具体杯型分温度的细节） |
| 无 | D 做法 | 留空 |
| 温度列 | E 温度 | 见下方展开 |
| 制作（正常糖）列的"蔗糖糖浆 X 克" | F 糖度=标准糖度 + G 蔗糖 + H 30 | |
| 七分糖/半糖列 | F 糖度=七分糖 + G 蔗糖 + H 该列数字 | |
| 三分糖列 | F 糖度=三分糖 + G 蔗糖 + H 该列数字 | |
| 无 | F 糖度=五分糖 | 默认 = 七分糖的 蔗糖用量 |
| 无 | F 糖度=不额外加糖 | **不写蔗糖行**，只展开其他原料 |
| 制作列"+"分隔的各段 | G 原料名称 + H 用量 | 跳过 PDF 中非奶茶机原料（见下） |
| 无 | I 原料排序 | 留空 |

## 温度展开规则

| PDF 温度列写法 | Excel E 列取值 |
|---|---|
| `全温度` | `正常冰`、`少冰`、`去冰`、`常温`、`热`（5 项） |
| `冰/少冰/去冰` | `正常冰`、`少冰`、`去冰`（3 项） |
| `冰/少冰` | `正常冰`、`少冰`（2 项） |
| `冰` | `正常冰`（1 项） |
| `热` | `热`（1 项） |
| `常温` | `常温`（1 项） |
| `冰沙` | `正常冰`（1 项，冰沙类产品；2026-08-13 用户规则：冰沙选项一律改为正常冰） |

## 杯型规则（2026-08 实测修正）

PDF 杯型列经常不写"大杯/中杯"字样，而是写杯型描述。按以下映射：

| PDF 杯型描述 | Excel C 列 |
|---|---|
| `咖啡专用杯`、`16A纸杯` | **中杯** |
| `22A纸杯`、`700塑杯`、`700磨砂注塑杯`、`22A荔枝纸杯` | **大杯** |
| PDF 明确写 `中杯` / `大杯` | 按原文 |
| `水果桶`、`专用打包袋`（吨吨桶类） | 按 PDF 实际（桶）或与用户确认 |
| PDF 同时给中杯/大杯两套配方 | 分别生成两组数据 |

## 原料顺序（生成时每组合下的行序）

1. `蔗糖`（糖度 ≠ "不额外加糖" 时存在）
2. 风味主料（果浆/果酱/果汁，如 凤梨果浆、速冻荔枝浆、西瓜汁）
3. 液体基底（茶汤/鲜牛乳/厚椰乳/酸奶）

> 注：历史导出数据（v1.0 等旧版本）原料顺序可能不同（如 果酱→蔗糖→茶），生成时以当前在用版本（全国北京路通用/全国标准/标准）的顺序为准。

## 原料拆分规则

PDF 的"制作（正常糖）"字符串示例：

```
蔗糖糖浆30克+黄金冻1.5漏勺（120克）+凤梨果酱1平塑勺（25克）+鲜牛乳40ml
```

按 `+` 拆分，对每一段：
1. **提取名称**：去除末尾用量单位（克/g/ml）。
2. **提取用量**：取段内第一个整数；若段内同时出现"X克"和"（Yg）"，取 Y（已换算后的克数）。
3. **名称标准化（2026-08 更新）**：**以配方正文（制作配方）里的名称为准**，不做额外映射。仅保留已确认的映射：
   - `蔗糖糖浆` → `蔗糖`（Excel 模板统一用蔗糖，已实测确认）
   - `凤梨果酱` → `凤梨果浆`（Excel 导出数据实测确认）
   - 其他（`速冻草莓果酱` / `冷冻芒果浆` / `鲜牛乳` / `厚椰乳` / `石榴汁` / `桃果肉饮料` 等）**原样保留**，按配方正文写法写入。
   - 即：用户 2026-08-12 明确规则——"以后以配方正文上的名称为准"，不要用标签表/物料对照表的叫法替换正文名称（例：配方正文写"石榴汁"就写"石榴汁"，不写成"石榴汁饮料浓浆"）。
4. **过滤非机器原料**（默认**不**写入 Excel）：`黄金冻`、`红西柚颗粒罐头`、其他罐头/果粒/小料——这些是手工添加。

## 原料顺序

每组合下按以下顺序：
1. `蔗糖`（糖度 ≠ "不额外加糖" 时存在）
2. 主料（果浆 / 果酱）
3. 基底乳（鲜牛乳 / 厚椰乳）

## 糖度展开顺序

固定为：`标准糖度` → `七分糖` → `五分糖` → `三分糖` → `不额外加糖`

## 典型映射示例

### 凤梨冰奶 / 正常冰 / 标准糖度

PDF 段：`蔗糖糖浆30克+黄金冻1.5漏勺（120克）+凤梨果酱1平塑勺（25克）+鲜牛乳40ml`

Excel 行：
```
A: 全国北京路通用
B: 凤梨冰奶
C: 大杯
E: 正常冰
F: 标准糖度
G: 蔗糖      H: 30
G: 凤梨果浆  H: 25
G: 鲜牛乳    H: 40
```

### 凤梨冰奶 / 正常冰 / 不额外加糖

PDF 无显式列；Excel 行：
```
A: 全国北京路通用
B: 凤梨冰奶
C: 大杯
E: 正常冰
F: 不额外加糖
G: 凤梨果浆  H: 25
G: 鲜牛乳    H: 40
```

## 边界与例外

- **冰类限定饮品**（如杨枝甘露，仅 `冰/少冰/去冰`）：不允许"常温"或"热"组合。
- **杯型细节**：模板只用 `大杯`。若 PDF 出现 `中杯`/`小杯`，请向用户确认是否需要分杯型生成多组数据。
- **多版本号**：若 PDF 同时给多个品牌/区域的版本号，按版本号分行生成（每行所有原料都带相同版本号）。
